1. **下载**适合你系统的文件，按上面的方法打开。无需安装：她需要的一切都在
   里面。
2. **第一次打开时，向导会帮你搞定一切**：
   - **语言**：英语、西班牙语、法语、德语、葡萄牙语（巴西）、俄语、波兰语或简体中文。
   - **她的大脑**：
     - *在你的电脑上*：她会检查你的显卡显存和内存，推荐能装得下的最大
       模型。勾选 *自动安装和配置*，她就会安装 Ollama、下载模型，并
       确认它能正常回答。
     - *在互联网上*：用你的 ChatGPT 账号登录，或者粘贴某个服务商的密钥。
   - **外观和声音**：Lena、Marc 或光波，还有一个可以先试听再选的声音。
     只会下载你选中的那个声音。
   - **完成**：之后你可以直接去连接 WhatsApp、Telegram 等等。
3. **开始聊天吧**。在聊天框里输入 `/help` 查看命令。

你随时都可以从菜单里重新打开向导。更喜欢手动设置？用顶部栏的模型
按钮：*Gemini* 或 *Groq* 的免费密钥、你的 ChatGPT 账号，或者你自己的
[Ollama](https://ollama.com)、[LM Studio](https://lmstudio.ai) 或 llama.cpp，她会自己找到它们。

> **系统要求**：Windows 10 或 11（64 位）、Linux（64 位）或搭载 Apple Silicon 的 macOS（M1 或更新）。本地模型需要至少 5 GB 显存的显卡（12B 模型需要 9 GB）；最小的那些模型如果内存够大，也能在处理器上运行。用云端模型的话，什么电脑都行。

## 她能做的一切

<details>
<summary><b>🎭 你看到的她</b></summary>
<br>

- **视频角色**：每个角色就是一个文件夹，里面放着视频和剪切点。加入你自己的角色，
  它们就会出现在 *设置 › 外观* 里。
- **光波**：一个抽象、低调的形象，适合你不想看到脸的时候。
- **多个形象可选**：Lena、Marc 和光波，很快还会有更多，
  其中包括一些无审查的。
- **两种心情**：开心或生气。冒犯了她，连她发呆时的小动作都会变，而且会持续一阵子。
- **内置片段编辑器**：标出每个表情动作的开始和结束并打上标签。模型会自己学会
  新的表情动作。
- **紧凑模式**（F11）：收起视频，只在你旁边留一个小小的聊天窗口。
- 手动触发任意表情动作：`/beso`（亲吻）、`/triste`（难过）、`/lengua`（吐舌头）……

</details>

<details>
<summary><b>👀 她看到和听到的</b></summary>
<br>

- **你的摄像头或你的屏幕**，共享给她。绿色边框表示她正在看。
- **盯屏幕**：“编译完了告诉我”。
- **照片和文件**：把图片、PDF、Word、Excel 或 CSV 拖进聊天框。
- **实时语音**：她用神经网络语音说话（语言、音色和语速随你选），并在
  你说话时倾听。全部在你的电脑上完成，离线运行，什么都不用装：它是内置的，
  在 CPU 或显卡上运行，由你决定。你一开口就能打断她，不按回车也能发送。
- 直接在窗口里跟她**语音和视频通话**。

</details>

<details>
<summary><b>📱 她自己的账号：WhatsApp、电话、Meet、Telegram、电子邮件</b></summary>
<br>

她不是关在窗口里的聊天框：她可以拥有自己的账号，像其他人一样跟你联系。

- **完整的 WhatsApp**：扫二维码关联一个号码，她就有了一个真正的 WhatsApp 账号。她会聊天、
  发照片和语音消息，还能**接语音和视频通话**，带着她的脸和她的声音。
- **Google Meet 视频通话**：她用自己的 Google 账号加入，实时进行视频对话：
  她看得见你、听得见你，还会出声回答。
- **她自己的电话号码**（仅限 Windows）：配上一个 **USB 调制解调器和一张 SIM 卡**，她会读取收到的短信，并
  **接听**打到她号码上的**电话**。出于安全考虑，她从不自己发短信或打电话。
- **Telegram**：她自己的机器人。她会发文字、照片、她表情动作的视频和语音消息。开启
  *离开* 模式，你就能把她装在手机里随身带着，权限卡片也会发到那里，危险操作
  还需要输入 PIN 码。
- **电子邮件**：她会读你的邮件并帮你总结。发送之前她一定会先问你。
- **联系人**：由你决定谁可以跟她聊。每个联系人都有自己的标签页和自己的 Chati，
  历史记录和记忆各自独立，而且**无法使用你的工具**。

</details>

<details>
<summary><b>🧰 智能体：工具、技能和 MCP</b></summary>
<br>

- 用真正的浏览器**上网**：搜索、阅读网页、点击、填写表单、下载。长网页
  会由一个研究员子智能体来总结，免得塞满模型的记忆。
- **文件和命令**：读取、写入和编辑文件；执行命令（Windows 上用 PowerShell，Linux 和 macOS 上用
  bash）。
- **计划**：遇到长任务，她会写一份计划，一步一步打勾完成。
- **技能**：**直接从 GitHub** 导入（`user/repo`），也可以从 `.zip`、`.md` 或文件夹导入。
  Claude、Codex、Cursor 和 skills.sh 格式都支持。或者让她自己做一个新的：她自带一个
  用来创建技能的技能。
- **MCP 服务器**：通过 URL 添加任意服务器，一键开关它的工具。
- **模型路由**：没必要什么都用昂贵的模型。聊天设一个免费或轻量的模型，
  写代码设一个更强的（付费或免费）。每条消息都由路由器来决定：
  你的要求涉及代码时，她会自己转给程序员，你换话题时
  再回来。程序员的输出显示为紫色，所以你总能知道是谁在说话。也可以用
  `/programa` 和 `/chati` 手动切换。
- **提醒和重复任务**：“每 30 分钟提醒我喝水”，“明天 9 点
  告诉我……”，“不停地给我讲个故事”。

</details>

<details>
<summary><b>🛡️ 她能做什么，由你决定</b></summary>
<br>

- **手动**：动手之前，她会给你看一张卡片，上面有 *运行 / 始终允许 / 否*。这些
  卡片也会通过 Telegram 发到你的手机上。
- **自动**：该做什么她就做什么，但**仅限于你共享给她的文件夹内**。超出
  这些文件夹，就弹卡片。
- 危险命令需要 PIN 码。调制解调器从不发短信也不打电话。邮件不问你绝不发送。

</details>

<details>
<summary><b>🖥️ 模型：在你的电脑上或在云端，免费</b></summary>
<br>

| 在你的电脑上（私密、离线） | 在云端 |
|---|---|
| **Ollama**：向导可以帮你安装它并下载推荐的模型 | **用你的账号登录 ChatGPT**：就用你已经在付费的订阅，不需要 API |
| **LM Studio** | **Gemini**（AI Studio，免费额度） |
| **llama.cpp**：应用会用你的 `.gguf` 文件自己启动服务器，视觉模型也支持 | **Groq**、**Cerebras**、**Mistral**、**OpenRouter**，都有免费模型 |
| 任何兼容 OpenAI 的服务器 | OpenAI API 或其他任何兼容的 API |

- **热切换**：换模型不会丢失对话。给你喜欢的模型标上星标。
- **多个免费账号，一个接一个**：为同一个服务商添加多个密钥或账号
  并排好顺序。一个额度用完时她会察觉，切换到下一个，在聊天里告诉你，
  等第一个恢复后再切回去。把免费额度叠起来，你就能全天用上大模型。
- 在思考型模型上，**推理强度**随你选（关闭、自动、低、中、高）。
- 你随时都能看到模型的记忆用了多少，以及它写得有多快。令牌计数器
  会把上下文拆开来显示，用你的 ChatGPT 账号时还会显示你套餐的用量限制。

  <img src="docs/consumo.png" width="340" alt="上下文明细和用量限制">

</details>

<details>
<summary><b>🧠 记忆和性格</b></summary>
<br>

- **长期记忆**：她会记下重要的事，并在其他对话中想起来。你可以查看、
  搜索和删除她记住的内容。
- **永远用不完的上下文**：对话快满时，她会自己总结一下，然后
  继续聊。也可以用 `/compact` 手动压缩。
- **可编辑的人设**：在聊天标题栏切换角色，或者在一个 `.md` 文件里写你自己的。
  连她子智能体的内部指令都可以重写。
- 对话历史、多个标签页，可以编辑、删除或重新生成任何一条消息。
- 托盘图标，登录时自动启动。

</details>

<details>
<summary><b>⌨️ 命令</b></summary>

| `/beso`、`/triste`…… | 在视频里播放对应的表情动作（亲吻、难过……） |

</details>

## 隐私和免责声明
