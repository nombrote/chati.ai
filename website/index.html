Install

Nothing to install by hand: download, open, and a wizard sets everything up.

Windows10 · 11 (64-bit)Chati.AI-win-x64.zip Linux64-bitChati.AI-linux-x64.tar.gz macOSApple Silicon (M1 or newer)Chati.AI-osx-arm64.tar.gz
1

Open it

Windows: unzip and open ChatiAI.exe. Linux / macOS: tar xzf the file and run ./ChatiAI inside the folder.

2

Let the wizard set her up

Pick your language; she checks your graphics card memory and RAM and recommends the largest local model that fits, installing Ollama and the model for you. Or sign in with ChatGPT or paste a key from a cloud provider. Then choose her look and voice.

3

Start talking

Type /help in the chat to see the commands. You can open the wizard again any time from the menu.

Requirements: for local models, a graphics card with at least 5 GB (9 GB for the 12B model); the smallest ones also run on the processor if you have enough RAM. With cloud models any PC will do.

Not signed yet: if Windows shows a SmartScreen warning, click More info › Run anyway. If macOS won't open it, run xattr -dr com.apple.quarantine Chati.AI-osx-arm64 once.

Private by default

With a local model nothing leaves your PC: not the text, not the voice, not the image. Conversations, memories, keys and settings stay on your machine. With a cloud provider, what you type goes to that provider under its own terms.

18+ only

Chati.AI adds no content filters. Depending on the model and the character you choose, it can produce adult content. You are responsible for how you use it.
